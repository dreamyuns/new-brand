포인트 금액·횟수·확률 같은 운영 숫자를 바꾸는 화면입니다. 저장하면 다음 요청부터 바로 서버 계산에 반영됩니다. 이 페이지는 참여형 적립(출석·퀴즈·친구 추천)에 쓰이는 값을 자세히 다룹니다.

붉은 점선 상자 A~F 화면의 영역 빨간 숫자 영역 안의 기능 「N-N절」을 누르면 그 절만 팝업으로 열립니다 확정 정책서 근거 있음 프로토 기준 정책서에 아직 없음 미결 바뀔 수 있음
