퀴즈 관리 (어드민)

기준 정책서 리워드 어드민 v0.3 · 10-2절 · 참여형 적립 v0.8 · 3절 기준 구현물 pickoq_demo admin/admin3.js (2026-10-12) 캡처 2026-10-27 · PC 1440 최종수정 2026-10-27

고객 앱 「여행상식 퀴즈」(F-QUIZ)에 나갈 문항을 등록·수정하고, 문항별 광고를 연결하고, 출제 여부를 관리하는 화면입니다. 서버는 여기서 「출제함」으로 둔 문항 중 매일 회원마다 3개를 무작위로 뽑습니다.

읽는 법

붉은 점선 상자 A~E 화면의 영역 빨간 숫자 영역 안의 기능 「N-N절」을 누르면 그 절만 팝업으로 열립니다 확정 정책서 근거 있음 프로토 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 퀴즈 관리 전체

  • 매일 회원마다 「출제함」 문항 중 3개를 무작위로 뽑습니다(문항 수는 설정값 quiz_count). 그 회원이 이미 푼 문항은 기간 없이 빼고, 모자라면 가장 오래전에 푼 문항부터 다시 씁니다. 설정 「푼 문제 다시 출제 허용」을 켜면 제외를 풉니다(A-SET). (10-2절 · 3-6절)
  • 퀴즈의 정답은 사실이어야 합니다. 출처로 확인된 내용만 등록하고, 행정구역·면적·연도처럼 바뀌는 정보는 출제하지 않습니다. 해설에도 확인되지 않은 숫자를 넣지 않습니다. (3-7절)
  • 문항은 한 문장, 정답은 O 또는 X, 해설은 1~2문장 — 해설은 고객이 맞혀도 틀려도 항상 봅니다. (3-3절 · 3-5절)
  • 문항마다 광고 링크·버튼 문구를 붙일 수 있습니다. 고객 화면 해설 아래에 「광고」 표시와 함께 나오고, 눌러도 적립은 없습니다. (3-13절)
  • 틀린 문항이 발견되면 즉시 「출제 안 함」으로 바꿉니다. 감점이 없으므로 별도 보상은 없습니다. (3-8절 E4)
  • 등록·수정은 관리자 로그에 남습니다(quiz_edit). (13-1절)
  • 화면 공통 규칙(찾기는 [조회]를 눌러야 걸림 · 안내 띠 · 불러오는 중)은 어드민 정책서를 따릅니다. (제3조)

A-QUIZ-X1 문항 수정 (광고 사용)
1문항 (한 문장으로)
  • 필수. 비우면 "문항을 입력해 주세요".
중복 같은 문장이 이미 있으면 저장하지 않고 빨간 토스트 "이미 등록된 문항이에요"(등록·수정 모두) — 엑셀 일괄 등록이 이미 있는 문항을 건너뛰는 것과 같은 기준입니다.
2정답 O / X
3해설
  • 칸 이름 「해설 (정답 공개 후 항상 보여줍니다)」 — 고객 화면은 맞혀도 틀려도 해설을 보여줍니다.
  • 필수. 비우면 "해설을 입력해 주세요".
근거 정답·해설은 항상 제공 (3-5절)
4광고 사용
  • 「사용 안 함」 / 「사용 — 해설 아래에 광고 버튼 노출」. 사용으로 바꾸면 ⑤·⑥이 나타납니다.
5광고 링크
  • https://로 시작하는 주소. 고객이 누르면 새 창으로 열립니다.
광고를 「사용」으로 했는데 링크가 비어 있으면 저장하지 않고 "광고를 사용하려면 광고 링크를 입력해 주세요"(등록·수정 모두). 새 문항 등록(X2)에서도 광고 설정이 함께 저장됩니다.
6광고 버튼 문구 (12자 이내)
  • 비우면 고객 화면에 "자세히 보기"로 나갑니다.
운영 주의 문구가 해설과 어긋나면 안 됩니다 — 예: 「괌은 일본의 섬이다」(정답 X, 괌은 미국 자치령)에 「일본 숙소 보기」. 문항마다 해설과 맞는 문구로 등록합니다.
근거 문항별 광고 · 적립 없음 (3-13절) · 광고성 정보 표기 의무 미결 (제14조 #13)

8[저장] [취소]
  • 저장 성공 → 모달 닫힘 · 토스트 "저장했어요" · 목록 갱신. 실패 → 빨간 토스트(서버 문구).
  • 버튼 순서 [취소] [저장](R9). 입력이 있는 모달이라 배경을 눌러도 닫히지 않습니다(R10).

A-QUIZ-X3 엑셀 일괄 등록
1① 양식 내려받기
  • 예시 2건과 작성 안내가 든 .xlsx. 안내 3번 "해설은 정답을 공개한 뒤 항상 고객에게 보여줍니다." · 4번 "근거는 선택이에요. 비워 두어도 등록됩니다. 출처로 확인된 내용만 등록해 주세요."
2② 채우기 — 문항 · 정답(O/X) · 해설 (필수) · 근거 (선택)

3③ 파일 올리기 (.xlsx / .xlsm) → [업로드]
  • 모두 등록되면 토스트 "N건 등록했어요". 건너뛴 줄이 있으면 결과 모달 「N건 등록 · M건 건너뜀」에 줄 번호와 이유.
  • 건너뛰는 경우: 문항·정답·해설이 비었음 · 정답이 O/X가 아님 · 이미 등록된 문항. 근거는 비어도 등록(선택).
  • 엑셀로 올린 문항은 광고 없이 등록됩니다 — 광고는 하나씩 [수정]에서 붙입니다.
4노란 안내 "근거는 선택이에요. 비워 두어도 등록되지만, 출처로 확인된 내용만 등록해 주세요 (정책서 3-7절)."
  • 근거는 비어도 그 줄을 등록합니다. 문항·정답·해설이 비었거나 정답이 O/X가 아니거나 이미 있는 문항이면 건너뜁니다(③).
