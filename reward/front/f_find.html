하단 탭 [검색]의 첫 화면입니다(주소 /find). 예전 검색 메인(M01)이 여기로 옮겨 왔고, 맨 위에 리워드 머리(「어디로 떠날까요?」 + 공작)가 붙었습니다. AI로 문장 검색하거나 목적지·날짜·인원을 골라 검색합니다.

읽는 법

붉은 점선 상자 A~D 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 미결 바뀔 수 있음

시트별 동작
  • 목적지(X1·X2) — 입력 칸 + 「최근 검색」(있을 때 · 전체 삭제·하나씩 삭제) + 「인기도시」 10곳.
    글자를 치면 KAYAK 자동완성(도시 → 지역·공항 → 호텔 순, 입력한 글자 파랗게).
    최근 검색을 누르면 그때의 목적지·날짜·인원이 폼에 채워집니다(검색은 직접 눌러야 함).
    결과가 없으면 "검색 결과가 없어요".
  • 날짜(X3) — 달력에서 체크인·체크아웃 → 아래 "체크인 ○ · N박 · 체크아웃 ○" → [적용하기].
    지난 날은 고를 수 없습니다.
  • 인원·객실(X4) — 객실마다 성인(만 18세 이상)·아동(만 0~17세, 아동마다 나이 선택) · [+ 객실 추가](최대 8객실 — 넘으면 "최대 8객실까지 추가 가능합니다") · [적용하기].

예외 케이스

#상황화면 동작
E1목적지 없이 [검색하기]토스트 "목적지를 입력해주세요."
E2체크인이 지난 최근 검색을 고름날짜는 기본값으로 다시 채움
E3AI 검색이 검색으로 이어지지 않음이동 없이 안내 팝업 — 두 가지로 나뉩니다
· 숙소와 무관한 질문(날씨·환율 등 — 서버가 판단): 「숙소 검색만 도와드릴 수 있어요」 — 본문은 서버가 보낸 안내(지금 문구: "숙소 검색과 관련 없는 질문이라 검색하지 않았습니다. 지역·날짜 등 숙소 조건으로 다시 입력해 주세요.") · 서버 안내가 없으면 "지역·날짜 같은 숙소 조건으로 다시 입력해 주세요" + [다시 입력하기]
· 목적지를 못 읽음: 「어디로 여행하고 싶으세요?」 — 도시, 지역, 호텔명 모두 괜찮아요 / AI가 딱 맞는 숙소를 찾아드릴게요 + [다시 입력하기]
E4AI 검색 실패토스트 "잠시 검색이 원활하지 않아요. 다시 시도해 주세요."
