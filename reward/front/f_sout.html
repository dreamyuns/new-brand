숙소 상세에서 예약처를 누르면 뜨는 화면입니다. 예약처(아고다·호텔스닷컴 등) 사이트를 새 창으로 열고, 픽콕에는 「예약처 예약창을 열었어요」 화면이 남습니다. 예약은 예약처에서 하고, 픽콕은 예약을 「적립예정」으로 기록했다가 체크아웃 7일 뒤 포인트를 줍니다.

읽는 법

빨간 숫자 화면 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 표시 없음 = 정책서 근거 있음 프로토 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 아웃링크 · 예약 적립 전체

  • 예약·결제는 예약처에서 합니다. 예약처 주소에는 KAYAK이 넣어 준 내 추적 번호(트랙 ID)가 들어 있어, 예약처가 나중에 「누구의 예약인지」 알려 줍니다. 그래서 예약처 사이트에서 조건을 바꾸거나 벗어나면 적립이 끊길 수 있습니다(F-GUIDE 필독). 프로토 기준
  • 예약은 바로 적립되지 않습니다 — 「적립예정」으로 남았다가 체크아웃 7일 뒤 적립완료(기본 적립). 뽑기 몫은 적립완료 뒤 포인트 내역에서 뽑습니다. (포인트 3-2 · 4절 · #37)
  • 본인인증 전이면 확정될 때 적립대기로 넘어가고, 인증하면 지급됩니다. 화면에 금액은 그대로 보여 주되 「본인인증을 해야 적립돼요」를 알립니다. (참여형 1-6 · P71·P126)
  • [예약 완료 처리하기]는 시연용입니다 — 실서비스에서는 예약처 리포팅으로 예약이 자동으로 쌓이므로 이 버튼이 없습니다. 프로토 기준
  • 예약 완료 토스트는 「적립예정일」을 알려 줍니다 — 인증 회원 "예약을 기록했어요 · MM.DD 적립 예정" / 미인증 "예약을 기록했어요 · 본인인증을 해야 MM.DD에 적립돼요" (P95).

④ 예약 적립 흐름 — 여기서 끝나지 않는다 (#37)

아웃링크는 예약 적립의 시작입니다. 이어지는 화면은 각 화면기획서에 있습니다.

단계언제고객 화면어드민
① 예약예약처에서 결제(시연: [예약 완료 처리하기])포인트 내역 「적립예정」 카드 · 적립예정일 (F-POINT) · 알림 없음예약 적립 목록 「적립예정」 배지 (A-BOOK)
② 확정체크아웃 + 7일(하루 처리) · 시연: 어드민 [지금 확정]「적립완료」 · 기본 적립 지급 · 알림 「예약 적립 +NP」 · 뽑기 버튼 열림「적립완료」 · 적립일시
②′ 미인증이면확정 순간「적립대기」 배지 · 지급 보류 → 본인인증하면 한꺼번에 지급 + 알림 「적립대기 포인트 +NP」「적립대기」 배지 · 합계에서 빠짐
