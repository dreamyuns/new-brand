여행상식 퀴즈

기준 정책서 참여형 적립 v0.8 · 1·3절 기준 구현물 pickoq_demo static/app.js (2026-10-08) 캡처 2026-10-27 · 390×844 최종수정 2026-10-27

하루 한 번 OX 문제 3개를 풀고, 맞힌 문제마다 10P를 받는 화면입니다(0~30P). 한 문제에 한 번만 답할 수 있고, 틀려도 정답과 해설을 보여줍니다. 홈의 「오늘의 적립」에서 들어옵니다.

읽는 법

붉은 점선 상자 A~D 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 확정 정책서 근거 있음 프로토 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 여행상식 퀴즈 전체

  • 픽콕이 직접 출제하고 비용도 픽콕이 부담하는 기능입니다. 광고 상품이 아닙니다. (3-1절)
  • 계정당 하루 한 번, 3문제. 하루의 기준은 한국 시간 00:00~23:59, 서버 시각입니다. (3-2절 · 1-3절)
  • 문제는 O / X 두 가지로만 답합니다. 문항은 한 문장, 정답과 해설 1~2문장이 함께 등록됩니다. (3-3절)
  • 한 문제에 한 번만 답합니다. 고르면 바꿀 수 없고, 틀린 문제는 0P로 확정됩니다. 틀려도 정답과 해설은 보여줍니다. (3-5절)
  • 맞힌 문제마다 10P, 하루 결과는 0~30P. 포인트는 문제마다가 아니라 마지막 문제에 답하는 순간 한 번에 지급됩니다. (3-4절)
  • 그날의 3문제는 퀴즈 화면을 처음 연 순간 정해져 저장됩니다. 중간에 나갔다 와도 같은 문제를 이어서 풉니다. 이미 푼 문제는 기간 없이 다시 나오지 않습니다(모자라면 가장 오래전에 푼 문제부터 재사용). 어드민이 「푼 문제 다시 출제 허용」을 켜면 다시 나올 수 있습니다. (3-6절 · 3-8절 E1)
  • 로그인하지 않으면 문제를 가리고 로그인을 안내합니다. 포인트는 본인인증을 마친 회원만 받습니다 — 미인증 회원은 퀴즈 화면을 열 때(문제를 보기 전) 본인인증 시트가 뜨고, 인증을 마치면 퀴즈 화면이 이어서 열립니다. 다 푼 뒤에 막히면 푼 것이 헛수고가 되므로 처음에 묻습니다. (1-2절 · 1-6절)
  • 해설 아래에는 어드민에서 문항별로 지정한 광고 버튼이 나올 수 있습니다. 누르면 새 창이 열리고 적립은 없습니다. (3-13절)
  • 문제 수(3)·문항당 포인트(10P)는 어드민 설정값, 문항은 어드민 퀴즈 관리에서 등록합니다. (A-QUIZ 예정)

화면 공통 규칙
  • 2뎁스 화면 — 하단 탭이 보이지 않습니다.
  • A·B는 위에 고정, 내용이 길어지면 C·D만 스크롤됩니다(해설·광고가 붙으면 C가 길어짐).
  • 나가기: [←] 또는 기기 뒤로가기 → 직전 화면. 단, 마지막 문제에 답하고 [결과 보기]를 누르지 않았으면 확인창(X1)을 먼저 띄웁니다.
  • 퀴즈 화면에 있는 동안에는 알림 토스트를 띄우지 않습니다 — 문제 푸는 것을 방해하지 않도록(C-LAYER 겹침 규칙).

1진행 표시
  • 막대 3개 + 「N / 3」. 푼 문제 = 노랑, 지금 문제 = 파랑, 남은 문제 = 회색.
근거 헤더에 진행 표시 1/3 (3-11절)
2문제
  • 한 문장. 어드민에 등록된 문항을 서버가 골라 줍니다.
데이터 ← questions[].question
근거 한 문장으로 쓰고 두 가지를 동시에 묻지 않는다 · 출처로 확인된 사실만 · 바뀌는 정보(행정구역·수치·연도) 출제 금지 (3-3절 · 3-7절)
3[O 맞아요] [X 아니에요]
  • 누르면 서버가 채점합니다. 한 번 고르면 두 버튼 모두 누를 수 없게 바뀌고, 고른 쪽만 색이 남습니다(O = 파랑, X = 빨강).
  • 연달아 눌러도 한 번만 처리됩니다.
  • 본인인증 전 회원은 이 화면에 들어오기 전에 인증을 마치므로(④ X4), 여기서 다시 묻지 않습니다. 서버는 채점 때 한 번 더 확인합니다.

4고르기 전 안내

8안내 카드 (카드 대신)

  • 오늘 완료: "오늘 퀴즈 완료 / 3문제 중 N개를 맞혀 NP를 받았어요. 내일 새로운 문제로 다시 만나요." — 한 개라도 맞히면 🎉, 0개면 🙂
  • 이 두 상태에서는 D(규칙 안내)가 나오지 않습니다.
근거 비로그인은 문항을 가리고 로그인 유도 · 완료 후 재진입 시 「오늘 완료」 + 내일 안내, 재참여 불가 (3-11절 · 1-5절)
9불러오는 중
  • "잠시만 기다려 주세요" — 문제를 받는 동안 화면 안에서만 표시합니다(L-INLINE).
  • 문항이 하나도 없으면 토스트 "출제할 문제가 없어요"를 띄웁니다.
5결과 · 정답 · 해설
  • 정답: 초록 상자 "✓ 정답이에요!" / 오답: 분홍 상자 "✕ 아쉬워요"
  • 그 아래 "정답 : O (맞아요)" 또는 "정답 : X (아니에요)"와 해설 1~2문장 — 맞혀도 틀려도 항상 보여줍니다.

6광고 버튼 「광고 · [문구] ›」

  • 누르면 새 창으로 광고 페이지가 열립니다. 포인트는 주지 않습니다.
  • 「광고」 표시를 항상 붙입니다.
데이터 ← link · link_label (광고 꺼진 문항은 비어서 옴 → 버튼 숨김)
운영 주의 광고 문구가 해설과 어긋나지 않게 등록해야 합니다 — 예: 「괌은 일본의 섬이다」(정답 X, 괌은 미국 자치령)에 「일본 숙소 보기」가 연결된 사례가 있음 (A-QUIZ에서 다룸)
근거 문항별 광고 · 새 창 · 적립 없음 · 미지정 시 숨김 (3-13절) · 광고성 정보 표기 의무 해당 여부는 미결
7[다음 문제] / [결과 보기]
  • 답을 고른 뒤에만 나옵니다. 1·2번 문제 → [다음 문제], 3번 문제 → [결과 보기].
  • 3번에 답하는 순간 포인트는 이미 지급되어 있습니다. [결과 보기]는 결과를 보여줄 뿐입니다.
  • [결과 보기] → 맞힌 게 있으면 적립 연출(X2), 0개면 안내 토스트(X3) → 오늘 완료 상태(B4·C7)
근거 지급 시점은 세트 완주 시 일괄 — 중간 이탈 시 부분 지급 없음 (3-4절)
D

규칙 안내 「이렇게 쌓여요」

확정
F-QUIZ-D1 문제를 푸는 동안
1고정 문구 6줄
  • 하루 한 번, 3문제를 풀 수 있어요. (한국 시간 기준)
  • 맞히면 문항당 10P, 모두 맞히면 30P예요.
  • 한 문제당 한 번만 답할 수 있어요. 고르면 바꿀 수 없어요.
  • 틀리면 그 문항은 0P예요. 대신 정답과 해설을 알려드려요.
  • 포인트는 마지막 문제를 푼 순간 한 번에 들어와요.
  • 마지막 문제를 풀면 [결과 보기]에서 몇 개 맞혔는지 확인할 수 있어요.

④ 화면 위에 뜨는 것

전체 화면을 덮으므로 자르지 않습니다. 공통 동작은 C-LAYER를 따릅니다.

F-QUIZ-X1 결과를 안 보고 나갈 때 — 확인창
1제목 "결과를 보고 나가실래요?"
2안내 문구
  • "결과 화면에서 몇 개 맞혔는지와 받은 포인트를 볼 수 있어요. 적립은 이미 끝났으니 나중에 포인트 내역에서도 확인할 수 있어요."
근거 적립은 마지막 답에서 이미 끝났으므로 「안 누르면 못 받는다」처럼 사실과 다른 말을 쓰지 않는다 (3-4절)
3[그냥 나가기]
  • 확인창을 닫고 직전 화면으로 나갑니다.
4[결과 보기]
  • 확인창을 닫고 [결과 보기]를 누른 것과 같이 동작합니다(X2 또는 X3).
동작
  • 뜨는 때: 3번에 답했고 [결과 보기]를 누르지 않은 채 [←]를 누를 때만. 배경을 눌러도 닫히지 않습니다(L-DIALOG).
  • 가운데 회색 빈 상자와 💸 아이콘은 구현 시 정리합니다(확인 항목이 없을 때 상자 숨김 · 돈과 무관한 확인은 일반 아이콘).

1적립 안내 띠
  • "🎉 NP 적립! / 여행상식 퀴즈 N문제 정답"
2+NP — 맞힌 수 × 10P
3내 포인트 (지급 후 잔액)
데이터 ← balance

  • 알림함에 "퀴즈 +NP · 3문제 중 N개를 맞혔어요" 1건, 포인트 내역에 「여행상식 퀴즈 N문제 정답」 1줄.

#상황화면·서버 동작
E11~2문제만 풀고 나감진행 상태가 저장됩니다. 같은 날 다시 들어오면 다음 문제부터 이어서. 부분 지급 없음
E2푸는 중에 자정이 지남진행 중이던 세트는 무효, 다음 날 새 세트로 시작. 이미 푼 문제는 재출제 제외에 포함
E3마지막 답 직후 네트워크 오류중복 지급 없음. 다시 열면 오늘 완료 상태로 보임
E4문항 정답이 잘못 등록됨어드민에서 즉시 비활성화. 감점이 없으므로 별도 보상 없음
E5탈퇴 후 재가입풀이 기록 초기화 — 모든 문항이 다시 출제 대상
E6계정 정지 중참여 불가 — 버튼 비활성 + 사유 안내 미결 화면 미정(구현물에 없음)
—문제를 불러오는 중 서버 처리 실패확인창 "잠시 후 다시 시도해 주세요" — "문제를 불러오지 못했어요" + 이유 · [닫기] [다시 시도](퀴즈 화면을 다시 엽니다) (C-LAYER R3)
—출제할 문항이 없음토스트 "출제할 문제가 없어요" — 운영 사고이므로 어드민에서 문항 수를 관리(현재 55문항 · 목표 100)
—이미 답한 문항에 다시 답 요청서버 409 "이미 푼 문제예요" — 화면은 바뀌지 않음
