여행상식 퀴즈

기준 실개발 고객 웹 feature/reward (2026-10-30) · 정책 참여형 적립 v0.8 · 3절 캡처 2026-10-30 · 390×844 · 시연 데이터 최종수정 2026-10-30

하루 3문제의 여행 상식 OX 퀴즈를 풀고, 맞힌 문제마다 포인트를 받는 화면입니다. 홈의 「오늘의 적립」에서 들어옵니다.

화면 모습은 디자인 확정 전입니다. 색·글꼴·크기·배치는 리워드 디자인이 나오면 바뀝니다. 이 문서는 기능과 정책을 기준으로 읽어 주세요. 캡처 속 문제·숫자는 시연 데이터입니다.

읽는 법

붉은 점선 상자 A~D 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 표시 없음 = 정책서 근거 있음 실개발 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 여행상식 퀴즈 전체

  • 하루 한 번, 3문제. 한국 시간 자정에 새 날이 됩니다. 문제 수·문항당 포인트는 어드민 설정값. (3-2절)
  • 그날 처음 화면을 열 때 서버가 문제를 정합니다 — 사용 중인 문제 가운데 이 회원이 아직 안 푼 문제에서 무작위로 고릅니다. 한 번 정해진 오늘 문제는 다시 열어도 같습니다. (3-6절)
  • O / X 중 하나를 고르면 바로 채점되고 바꿀 수 없습니다. 틀린 문항은 0P, 대신 정답과 해설을 보여 줍니다. (3-3 · 3-5절)
  • 포인트는 마지막 문제를 푼 순간 한 번에 들어옵니다(맞힌 개수 × 10P, 최대 30P). 3문제를 다 풀기 전에 나가면 그때까지 맞힌 것은 아직 지급 전입니다. (3-4절)
  • 안 푼 문제의 정답은 서버가 화면에 보내지 않습니다. 푼 문제만 내 답·정답·해설이 내려옵니다.
  • 본인인증 전 회원은 화면에 들어오자마자 본인인증 시트가 뜹니다. 시트를 닫으면 홈으로 돌아갑니다. (1-6절) 실개발 기준
