친구 추천

기준 실개발 고객 웹 feature/reward (2026-11-02) · 정책 참여형 적립 v0.8 · 4절 + 정책변경 C17 캡처 2026-11-02 · 390×844 · 시연 데이터 최종수정 2026-11-02

내 추천코드를 친구에게 보내고, 친구가 그 코드를 넣으면 둘 다 1,000P를 받는 화면입니다. 가입한 지 7일이 안 된 회원은 여기서 다른 사람의 코드를 넣을 수도 있습니다. 홈의 「더 모으기 — 친구 추천」으로 들어옵니다.

화면 모습은 디자인 확정 전입니다. 색·글꼴·크기·배치는 리워드 디자인이 나오면 바뀝니다. 이 문서는 기능과 정책을 기준으로 읽어 주세요. 캡처 속 코드·숫자는 시연 데이터입니다.

읽는 법

붉은 점선 상자 A~E 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 표시 없음 = 정책서 근거 있음 실개발 기준 정책서에 아직 없음(정책변경 모음에만 있음) 미결 바뀔 수 있음

⚙ 공통 정책 — 친구 추천 전체

  • 추천인 1,000P · 친구 1,000P(설정값). 포인트 유효기간은 적립일 + 1년. (4-3절)
  • 추천인의 적립은 월 20회까지(설정값) — 이번 달(한국 시간 1일~말일)에 실제로 받은 건수를 셉니다. 코드를 보내는 횟수는 제한이 없고, 상한을 넘어도 친구는 정상 지급됩니다. (4-3절)
  • 추천코드는 가입할 때 바로 1개 발급되고 바꿀 수 없습니다(영문 대문자 + 숫자 9자리). 예전 회원처럼 코드가 없으면 이 화면을 열 때 발급합니다. (4-2절) 실개발 기준 가입 즉시 발급(11-02)
  • 코드를 넣는 곳은 이 화면의 「추천코드 입력」뿐입니다 — 가입 후 7일 안, 아직 넣지 않은 회원에게만 보이고 한 번만 넣을 수 있습니다. 가입 화면에는 코드 칸이 없습니다. 실개발 기준 C17② 확인 요청 안내 문구는 「가입할 때 입력」
  • 각자 본인인증을 마쳐야 지급됩니다. 코드를 넣은 사람이 본인인증 전이면 그 몫은 적립대기, 추천인이 본인인증 전이면 추천인 몫이 적립대기 — 본인인증하는 순간 들어옵니다(추천인은 그때 월 상한을 다시 봄). (4-1절 · 1-6절)
  • 다른 회원의 이름은 보여 주지 않습니다. 화면에는 집계만, 언제 적립됐는지는 포인트 내역에서 봅니다.
