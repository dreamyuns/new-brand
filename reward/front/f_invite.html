기준 정책서 참여형 적립 v0.8 · 1·4절 기준 구현물 pickoq_demo static/app.js (2026-10-08) 캡처 2026-10-27 · 390×844 최종수정 2026-10-27

내 추천코드를 친구에게 보내고, 친구가 가입할 때 그 코드를 넣으면 친구와 나 모두 1,000P를 받는 기능입니다. 친구 추천 화면에서는 코드 확인·공유와 실적을 보고, 코드 입력은 가입 시트와 계정관리에서 합니다(⑤절).

읽는 법

붉은 점선 상자 A~G 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 확정 정책서 근거 있음 프로토 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 친구 추천 전체

  • 보상은 친구가 가입하면서 내 코드를 넣는 순간 양쪽에 바로 지급합니다(예약·이용 조건 없음). (4-1절)
  • 추천인 1,000P · 피추천인 1,000P. 포인트 유효기간은 적립일 + 1년. (4-3절)
  • 추천인의 적립은 월 20회까지 — 「친구가 내 코드를 넣어 내가 적립받은 횟수」를 셉니다. 코드를 보내는 횟수는 제한이 없고, 상한을 넘어도 친구는 정상 지급됩니다. 매월 1일 초기화. (4-3절 · 무신사 참고)
  • 추천코드는 가입할 때 계정당 1개 자동 발급, 변경 불가. 영문 대문자 + 숫자 9자리, 헷갈리는 글자(O·0·I·1·l)는 쓰지 않습니다. (4-2절)
  • 코드는 가입 화면에서 입력(주 경로) · 못 넣었으면 가입 후 7일 이내 계정관리에서. 피추천인은 하나의 코드만 쓸 수 있고 바꿀 수 없습니다. (4-2절)
  • 코드 확인은 [조회] 버튼으로 하고, 추천인 이름은 보여주지 않습니다(이름이 바뀔 수 있어 혼란). 초대 링크로 들어오면 코드를 자동으로 채우고 [조회]까지 자동 실행합니다. (4-2절 · 4-9절)
  • 추천 관계는 코드를 넣을 때 확정되고, 지급은 각자 본인인증을 마치면 각자 받습니다 — 미인증 쪽 몫은 「적립대기」로 두었다가 인증하면 지급(기한 없음). 적립대기 금액은 화면에 보여주지 않습니다. 미인증 회원도 코드를 넣을 수 있고, 이때는 연출·금액 없이 토스트 "추천코드를 등록했어요. 본인인증하면 적립돼요". 추천인 월 20회는 실제로 지급한 달로 세고, 적립대기였던 추천인 몫이 인증 때 그 달 상한을 넘으면 지급하지 않습니다. (1-6절)
  • 같은 사람·같은 명의·같은 기기 다계정, 탈퇴 후 재가입, 공개 배포, 제휴 파트너는 제외합니다. (4-4절)
  • 로그인하지 않으면 코드를 보여주지 않고 로그인을 안내합니다. (4-7절)
  • 지급액(1,000P)·월 상한(20회)은 어드민 설정값입니다. (A-SET 예정)
