광고를 누르고 광고주 페이지에 정해진 초 동안 머물면 포인트가 쌓이는 화면입니다. 하단 탭 [혜택]으로 들어옵니다. 혜택 사업 정책(광고 중개 방식·정산·단가)은 아직 정해지지 않아, 이 문서는 지금 화면의 기능만 다룹니다.

읽는 법

붉은 점선 상자 A~E 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 표시 없음 = 정책서 근거 있음 프로토 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 혜택 전체

  • 1뎁스 화면(하단 탭 보임). 비로그인도 목록은 보고, 광고를 누르면 로그인 시트가 뜹니다. (1-1절)
  • 목록에는 어드민에서 노출이 켜져 있고 노출 기간 안인 광고만 나옵니다. (1-1절)
  • 같은 광고는 회원당 한 번만 적립됩니다. (0절)
  • 본인인증 전 회원은 광고 페이지로 나가기 전에 본인인증을 묻습니다 — 다녀온 뒤 막히면 광고만 보고 못 받기 때문입니다. (1-5절 · 참여형 1-6절)
  • 광고 페이지는 구현에서 시연용 대체 화면입니다. 실제 체류 확인·적립 통보 방식은 미결입니다. (2절 · 미결 R-O1)

  • 광고 순서는 등록 순서입니다(어드민에 순서를 바꾸는 기능은 없음).

미결 R-O1

새 창으로 열립니다. 실제 서비스에서는 광고주 페이지로 바로 가고, 체류 확인·적립 통보 방식(중개사 포스트백 등)은 정해지지 않았습니다. 아래는 시연 화면의 동작입니다.

F-OFFER-X1 기다리는 중
F-OFFER-X2 적립됨
F-OFFER-X3 이미 참여
F-OFFER-X4 비로그인
1주소 줄
  • 광고주 링크 주소.
2「광고」 표시
3제목 · 광고주 (아래 설명 상자)
4상태 문구
  • X1 "조금만 기다려 주세요 · 이 화면에 N초 머물면 NP가 적립돼요"
  • X2 "NP 적립됐어요! · 픽콕으로 돌아가면 포인트가 올라가 있어요"
  • X3 "이미 참여한 혜택이에요 · 같은 광고는 한 번만 적립돼요"
  • X4 "로그인이 필요해요 · 픽콕에서 로그인한 뒤 다시 참여해 주세요"
  • 실패 "적립하지 못했어요" + 서버 사유("종료된 광고예요" 등)
5"적립이 끝나면 이동 버튼이 나타나요"
  • 기다리는 동안만.
6[광고주 페이지로 이동하기]
  • 적립이 끝나야(또는 이미 참여·비로그인) 나타납니다. 누르면 이 창이 광고주 링크로 이동합니다. 픽콕에는 적립이 끝난 순간 이미 결과를 알렸습니다.
7카운트 → ✓
  • 1초마다 줄고, 0이 되면 서버에 적립을 요청합니다.
8"이 화면은 시연용입니다…"
