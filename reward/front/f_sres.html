검색 결과

기준 실개발 고객 웹 feature/reward (2026-11-02) · 지도 보기는 feature/search-map (2026-11-03) · 정책 Phase1 메타서치 정책서(S01 · S01-MAP) + 정책변경 C13 · C25 캡처 2026-11-02 · 지도 보기 2026-11-03 · 390×844 · 실제 KAYAK 응답(캡처 시점) 최종수정 2026-11-03

검색 탭에서 [검색하기]를 누르거나 AI 검색을 하면 나오는 숙소 목록입니다(주소 /search?destination=…). 숙소와 가격은 호텔스컴바인(KAYAK)에서 받아 옵니다. 숙소를 누르면 새 창으로 숙소 상세(F-SDET)가 열립니다.

읽는 법

붉은 점선 상자 A~E 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 미결 바뀔 수 있음

⚙ 공통 정책 — 검색 결과 전체

  • 주소(URL)가 검색 조건의 원본입니다 — 목적지·날짜·인원·필터·정렬이 모두 주소에 들어 있어, 주소를 공유하거나 새로고침해도 같은 결과입니다.
    목적지가 없는 주소로 들어오면 첫 화면으로 보냅니다.
  • KAYAK은 결과를 여러 번에 나눠 보내므로, 받는 동안 목록이 채워지고 가격이 바뀔 수 있습니다.
    처음 결과가 올 때까지 회색 뼈대(스켈레톤)를 보여 줍니다.
  • 한 번에 50곳씩 보여 주고 [목록 더보기]로 50곳씩 더 받습니다.
  • 필터·정렬은 서버가 처리합니다.
    필터를 바꾸면 주소만 바뀌고(뒤로가기 기록에 쌓이지 않음), 조건(목적지·날짜·인원)을 바꾸면 새 검색입니다 — 이때 적용 중인 필터는 모두 초기화됩니다.
  • 숙소 상세는 새 창으로 엽니다 — 결과 목록(조건·스크롤·더보기)을 그대로 두기 위해.
  • AI 검색 결과가 0곳이면(KAYAK에는 숙소가 있는데 문장에서 읽은 조건 때문에 다 빠진 경우) 조건을 하나씩 풀어 자동으로 다시 찾습니다 — 한 문장에 최대 2번.
    푸는 순서: 분위기(테마) → 전망(「뷰 좋은」) → 평점 8점(「좋은·훌륭한」 같은 칭찬 말로 걸린 것만) → 편의시설(마지막에 말한 것부터 하나씩) → 숙소 종류 → 가격.
    목적지·날짜·인원·정렬·성급과, 평점 칩으로 직접 고른 평점은 풀지 않습니다.
    풀 때마다 토스트로 알립니다(예외 E11).
    폼 검색에는 없습니다.
  • 목록 아래 가운데 [지도로 보기] 떠 있는 버튼 → 같은 결과를 지도로(⑤). C25
  • 오른쪽 아래 [적립필독] 떠 있는 버튼 → F-GUIDE. C13⑤

  • 「이 지역 검색」은 없습니다 — 지도를 옮겨도 결과는 그대로입니다. (C25①)
