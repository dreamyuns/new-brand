검색 결과

기준 실개발 고객 웹 feature/reward (2026-11-02) · 정책 Phase1 메타서치 정책서(S01) + 정책변경 C13 캡처 2026-11-02 · 390×844 · 실제 KAYAK 응답(캡처 시점) 최종수정 2026-11-02

검색 탭에서 [검색하기]를 누르거나 AI 검색을 하면 나오는 숙소 목록입니다(주소 /search?destination=…). 숙소와 가격은 호텔스컴바인(KAYAK)에서 받아 옵니다. 숙소를 누르면 새 창으로 숙소 상세(F-SDET)가 열립니다.

화면 모습은 디자인 확정 전입니다. 이 문서는 기능과 정책을 기준으로 읽어 주세요. 캡처 속 숙소·가격은 캡처한 순간의 실제 값이라 다시 검색하면 달라집니다.

읽는 법

붉은 점선 상자 A~E 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 실개발 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 검색 결과 전체

  • 주소(URL)가 검색 조건의 원본입니다 — 목적지·날짜·인원·필터·정렬이 모두 주소에 들어 있어, 주소를 공유하거나 새로고침해도 같은 결과입니다. 목적지가 없는 주소로 들어오면 첫 화면으로 보냅니다.
  • KAYAK은 결과를 여러 번에 나눠 보내므로, 받는 동안 목록이 채워지고 가격이 바뀔 수 있습니다. 처음 결과가 올 때까지 회색 뼈대(스켈레톤)를 보여 줍니다.
  • 한 번에 50곳씩 보여 주고 [목록 더보기]로 50곳씩 더 받습니다.
  • 필터·정렬은 서버가 처리합니다. 필터를 바꾸면 주소만 바뀌고(뒤로가기 기록에 쌓이지 않음), 조건(목적지·날짜·인원)을 바꾸면 새 검색입니다 — 이때 적용 중인 필터는 모두 초기화됩니다.
  • 숙소 상세는 새 창으로 엽니다 — 결과 목록(조건·스크롤·더보기)을 그대로 두기 위해.
  • 오른쪽 아래 [적립필독] 떠 있는 버튼 → F-GUIDE. 실개발 기준 C13⑤

시트별 동작
  • 필터(X1) — 정렬(인기순 · 낮은 가격순 · 평점 높은순) · N박 가격 범위(최저~최대 슬라이더) · 성급(성급없음 · 1~5성) · 숙소 유형(5개 + 더보기) · 평점 7.0점 이상만 보기. 아래 [초기화] · [결과 N개 보기](고르는 동안 N이 바뀜). 적용하면 토스트 "필터가 적용됐습니다".
  • AI 필터(X2) — "원하는 조건을 입력해 보세요 · 성급·가격·시설을 변경하면 → 조건에 맞게 결과를 다시 보여드려요" · 입력 · [적용하기]. 반영할 수 있는 조건(필터·정렬)만 바꾸고, 지역·날짜·인원처럼 반영할 수 없는 말은 토스트로 안내합니다. 반영할 조건이 없으면 "반영할 조건을 찾지 못했어요".
  • 검색 수정(X3) — 목적지 · 날짜 · 인원·객실 + [검색하기].
