하루 한 번 [출석하기]를 누르면 도장이 쌓이고, 6번째 출석에 선물상자(추가 포인트)가 열리는 화면입니다. 홈의 「오늘의 적립」에서 들어옵니다.

붉은 점선 상자 A~D 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 확정 정책서 근거 있음 프로토 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 출석체크 전체

  • 하루의 기준은 한국 시간 00:00~23:59입니다. 서버 시각으로 판단하고, 휴대폰 시간 설정이나 해외 체류와 상관없습니다. (1-3절)
  • 로그인하지 않아도 화면은 보여줍니다. 참여 버튼을 누르면 로그인을 안내합니다. (1-2절)
  • 포인트는 본인인증을 마친 회원에게만 줍니다. 가입 때는 인증을 받지 않으므로, 미인증 회원이 출석 버튼을 누르면 본인인증 시트를 띄우고 인증을 마치면 그 자리에서 출석을 처리합니다. 서버도 출석 요청 때 한 번 더 확인합니다. (1-6절)
  • 숫자는 어드민 설정값을 따릅니다 — {P} = 출석 1회 포인트(attend_point, 기본 10), {N} = 카드 칸 수(attend_card_size, 기본 6). 이 페이지의 「10P」「6번째」「5칸」은 기본값일 때의 모습입니다.

  • 계정당 하루 한 번. 같은 날 두 번 요청이 오면 서버가 막습니다. 버튼을 연달아 눌러도 한 번만 지급됩니다. (1-4절 · 2-2절)
  • 출석 카드는 6칸 한 장이 끝없이 반복됩니다. 하루 빠져도 도장은 사라지지 않고, 주·월이 바뀌어도 초기화하지 않습니다. (2-3절)

  • 출석으로 포인트가 쌓이면 알림함에 1건이 기록됩니다. (2-11절)
  • 출석 포인트(10P)·카드 칸 수(6)·추가 포인트 구간별 비중은 어드민 설정값입니다. (2-6절 · A-SET 예정)

② 페이지 구성

화면은 위에서부터 4개 영역으로 이루어집니다. 예시는 로그인 · 오늘 아직 출석하지 않은 상태입니다.

영역들어가는 요소배치·동작상태에 따라 바뀌는 것
A 상단 바[←] 뒤로 · 제목 「출석체크」 · 알림 종화면 맨 위 · 왼쪽 정렬 · 종은 오른쪽 끝비로그인이면 알림 종 없음
B 상태 영역캐릭터 · 연속 출석 일수 · 기준 시각 안내파란 배경 · 가운데 정렬 · A와 한 덩어리비로그인이면 「로그인이 필요해요」 문구로 바뀜
C 출석 카드칸 수 · 도장 6칸 · 출석 버튼 · 안내 문구흰 카드 · B 아래쪽에 살짝 겹쳐 올라옴도장 상태 · 버튼 문구 · 안내 문구 (4가지 상태)
D 규칙 안내「이렇게 쌓여요」 고정 문구 5줄흰 카드 · C 아래바뀌지 않음
화면 공통 규칙
  • 2뎁스 화면입니다 — 하단 탭(홈·검색·혜택·My)이 보이지 않습니다.
  • A·B는 위에 고정되고, 내용이 화면보다 길어지면 C·D만 스크롤됩니다.
  • 나가기: A의 [←] 또는 기기 뒤로가기(C-LAYER R6) → 들어오기 직전 화면(보통 홈)
  • 화면에 들어올 때마다 서버에서 오늘 출석 여부·도장 수·연속 일수를 새로 받습니다.

  • 비로그인은 모두 「남음」으로 보입니다.
