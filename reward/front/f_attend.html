출석체크

기준 실개발 고객 웹 feature/attend-quiz-design (2026-11-12) · 정책 참여형 적립 · 2절 캡처 2026-11-12 · 390×844 · 시연 데이터 최종수정 2026-11-12

하루 한 번 [출석하기]를 누르면 도장이 쌓이고, 6번째 출석에 선물상자(추가 포인트)가 열리는 화면입니다. 홈 「매일 포인트 GET!」의 출석 칸에서 들어옵니다(비로그인도 바로 들어옴).

디자인 시안이 반영된 개발 화면입니다. 시안과 다른 곳은 개발 화면이 기준입니다(PO 결정으로 바뀐 문구·칸 등). 캡처 속 숫자는 시연 데이터입니다.

읽는 법

붉은 점선 상자 A~D 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 표시 없음 = 정책서 근거 있음 실개발 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 출석체크 전체

  • 하루 한 번, 한국 시간 자정에 새 날이 됩니다. 이미 출석한 날 다시 요청하면 서버가 막고 토스트로 알립니다. (2-2절)
  • 출석 카드는 6칸 — 1~5번째 출석은 각 10P, 6번째 출석에 선물상자(출석 10P + 추가 10~100P · 꽝 없음). 6번째를 채우면 다음 카드가 새로 시작됩니다. 칸 = 지금까지 출석한 횟수를 6으로 나눈 나머지. 칸 수·포인트는 어드민 설정값. (2-3 · 2-4절)
  • 추가 포인트는 [출석하기]를 누른 순간 서버가 정합니다. 선물상자는 결과를 보여 주는 연출일 뿐이라, 상자를 열기 전에 나가도 포인트는 이미 들어가 있습니다. (2-4절)
  • 하루 빠져도 도장은 사라지지 않습니다. 「N일 연속 출석」은 오늘(또는 어제)부터 이어진 날 수로, 보상과 무관합니다.
  • 적립은 본인인증 없이 됩니다(본인인증은 포인트를 쓸 때만). 실개발 기준 C48
  • 비로그인도 화면에 들어올 수 있고, [로그인 후 출석하기]를 누르면 로그인 안내 모달이 먼저 뜹니다 → [로그인하기]면 로그인 시트. 로그인한 뒤에는 이 화면에 그대로 머물고, 출석은 다시 눌러야 합니다(자동 진행 없음). 실개발 기준 C37
  • 적립 뒤에는 흰 적립 연출이 뜨고 6초 뒤 스스로 닫힙니다([✕]로 먼저 닫을 수 있음 · [확인] 버튼 없음). 실개발 기준 C50
  • 서버 처리 실패는 확인창 "출석하지 못했어요" + [다시 시도] — 같은 요청을 한 번 더 보내고, 이미 지급됐으면 서버가 막습니다(C-LAYER R3).
