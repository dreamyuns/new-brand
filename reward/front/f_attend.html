출석체크

기준 실개발 고객 웹 feature/reward (2026-10-30) · 정책 참여형 적립 v0.8 · 2절 캡처 2026-10-30 · 390×844 · 시연 데이터 최종수정 2026-10-30

하루 한 번 [출석하기]를 누르면 도장이 쌓이고, 6번째 출석에 선물상자(추가 포인트)가 열리는 화면입니다. 홈의 「오늘의 적립」에서 들어옵니다.

화면 모습은 디자인 확정 전입니다. 색·글꼴·크기·배치는 리워드 디자인이 나오면 바뀝니다. 이 문서는 기능과 정책을 기준으로 읽어 주세요. 캡처 속 숫자는 시연 데이터입니다.

읽는 법

붉은 점선 상자 A~D 화면의 영역 빨간 숫자 영역 안의 기능 — 마우스를 올리면 설명과 함께 강조 「N-N절」을 누르면 그 절만 팝업으로 열립니다 표시 없음 = 정책서 근거 있음 실개발 기준 정책서에 아직 없음 미결 바뀔 수 있음

⚙ 공통 정책 — 출석체크 전체

  • 하루 한 번, 한국 시간 자정에 새 날이 됩니다. 이미 출석한 날 다시 요청하면 서버가 막고 토스트 "이미 참여했어요". (2-2절)
  • 출석 카드는 6칸 — 1~5번째 출석은 각 10P, 6번째 출석에 선물상자(출석 10P + 추가 10~100P · 꽝 없음). 6번째를 채우면 다음 카드가 새로 시작됩니다. 칸 수·포인트는 어드민 설정값. (2-3 · 2-4절)
  • 추가 포인트는 [출석하기]를 누른 순간 서버가 정합니다. 선물상자는 결과를 보여 주는 연출일 뿐이라, 상자를 열기 전에 앱을 닫아도 포인트는 이미 들어가 있습니다. (2-4절)
  • 하루 빠져도 도장은 사라지지 않습니다. 「N일 연속」은 재미로만 보여 주고 보상과 무관합니다.
  • 본인인증 전 회원이 누르면 본인인증 시트가 먼저 뜨고, 마치면 출석을 이어서 합니다. (1-6절)
  • 서버 처리 실패는 확인창 "출석하지 못했어요" + [다시 시도] — 같은 요청을 한 번 더 보내고, 이미 지급됐으면 서버가 막습니다(C-LAYER R3).
