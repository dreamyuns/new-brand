2-2. 기기 알림 권한 [구현] [참고] 05 · 02 3-4

  • 휴대폰의 픽콕 알림 권한 상태를 보여 준다. 토글은 만들지 않는다 — 권한은 휴대폰 설정에서만 바꿀 수 있다.
  • 허용: "알림을 받을 수 있어요" + 「✓ 허용됨」
  • 거부: "꺼져 있어 앱 알림을 받을 수 없어요"(빨간 글씨) + [설정 열기] → 휴대폰 설정의 픽콕 알림 화면으로 이동
  • 마케팅 동의가 켜져 있는데 권한이 꺼져 있으면 안내 "기기 알림이 꺼져 있어 앱 푸시는 오지 않아요. 이메일은 계속 받아요."

2-3. 마케팅 정보 수신 동의

항목 내용 근거
형태 토글 · 보조 설명 "이벤트·혜택 소식을 받아요" [구현]
초기값 가입 때 고른 [선택] 마케팅 동의값(서버 marketing_agree) 회원 정책서 1-3 — 구현은 가입 직후에만 맞고, 다시 로그인하면 서버 값과 상관없이 켜짐으로 보인다(#44 — PO 제외, 광고성 알림과 함께)
적용 채널 이메일 + 앱 푸시 통합 1개 (채널별로 나누지 않음) [참고] 05 2-2
켤 때 토스트 "마케팅 수신에 동의했어요" [구현]
끌 때 토스트 "마케팅 수신을 철회했어요 · 예약된 광고성 알림은 취소돼요" — 예약된 광고성 알림 전부 취소 [구현] [참고] 05 2-2
일시 토글 아래 「동의 YYYY.MM.DD HH:MM」(초록) / 「철회 YYYY.MM.DD HH:MM」(회색) — 마지막 처리 일시. 광고성 정보 전송의 증빙이라 철회도 기록한다 [구현] [참고] 02 3-3
저장 서버에 동의값·일시를 저장하고, 화면을 열 때 서버 값을 보여 준다. 어드민 광고성 알림 발송은 이 값을 기준으로 대상을 고른다 구현은 화면에서만 바뀌고 일시도 고정값(2026.09.15 14:22) — 철회해도 어드민 광고 발송 대상(marketing_agree=1)에 그대로 남는다. 수정 요청 #44는 PO 제외(2026-10-27) — 광고성 알림을 이번 범위에서 뺐으므로(알림 정책서 1-2), 광고성 알림을 넣을 때 함께 고친다
약관 전문 설정에는 없다 — 마이페이지 › 약관·정책 › 「마케팅 정보 수신 동의」에서 본다 [구현] (앱 정책 05는 설정 안 바텀시트 — 리워드는 구현 기준)

2-4. 언어 · 통화 [구현] [참고] 05 2-3

언어 「한국어」 · 통화 「KRW」를 회색 글씨로 고정 표시한다. 누를 수 없다. 아래 안내 "지금은 한국어·KRW로만 제공돼요."

2-5. 앱 버전 [구현] [참고] 05 2-4

  • 최신: 「앱 버전 1.0.0」 + "최신 버전이에요"
  • 새 버전 있음: 「새 버전 N이 나왔어요」(빨간 글씨) + [업데이트] → 앱 스토어
  • 앱을 막는 강제 업데이트와는 별개다 — 여기는 사용자가 찾아와 누르는 확인이다.

항목 내용 근거

안내 목록 위 "찾는 답이 없으면 화면 우측 아래 [💸 필독]도 확인해 보세요." [구현]

약관 조항 내용은 PO가 나중에 정리한다(2026-10-27). 지금 구현물의 이용약관은 메타서치 픽콕 v0.10 목차라 리워드 조항(출석·퀴즈·친구 추천·현금 전환·픽샵·본인인증)이 없다.

항목 내용 근거
