# 항목 지금 화면 근거
1 혜택이란 광고주의 광고를 누르고 광고주 페이지에 정해진 초 동안 머물면 포인트 적립 [구현]
2 보상 광고마다 어드민이 정한 포인트(시연 데이터는 모두 10P) · 체류 초(시연 3초) [구현]
3 한 번만 같은 광고는 회원당 한 번만 적립 [구현]
4 참여 자격 로그인 + 본인인증 — 광고 페이지로 나가기 전에 인증을 묻는다 [구현] 참여형 1-6
5 광고주 페이지 구현은 시연용 대체 화면(/ad/{번호})이 체류를 세고 적립한다. 실제는 광고주 페이지로 바로 가고 중개사가 체류를 확인해 알려 준다 [구현] 미결 R-O1

1. 고객 — 혜택 탭

1-1. 진입·공통

  • 하단 탭 [혜택] (1뎁스 · 하단 탭 보임). 홈의 「혜택」 진입 카드에서도 들어온다(F-HOME F). [구현]
  • 광고 목록은 어드민에서 노출이 켜져 있고 노출 기간 안인 것만 보인다(기간이 비면 제한 없음). 정렬은 등록 순서(어드민에 순서 바꾸는 기능은 없음). [구현]
  • 비로그인도 목록은 본다. 광고를 누르면 로그인 시트. [구현]

1-2. 위쪽

상태 표시 근거
로그인 「사용 가능 포인트」 · 잔액 · "지금 받을 수 있는 혜택 NP · N개"(아직 안 받은 광고의 합) · [🛍️ 픽샵 쇼핑 — 포인트로 바로 구매] → 픽샵 [구현]
비로그인 「N개」(전체 광고 수) · "클릭하고 잠깐만 머물면 포인트가 쌓여요" · 아래 띠 "로그인하면 혜택을 보고 바로 적립할 수 있어요" [로그인] [구현] — 숫자 대신 「잠깐만」(광고별 체류가 달라서 · #48 10-28)

1-3. 분류

  • 칩: 「전체 N」 + 어드민에 등록된 분류(여행 · 금융 · 쇼핑 · 생활 · 게임 중 광고가 있는 것) — 칩마다 광고 수. [구현]
  • 칩을 누르면 그 분류만. 목록은 분류별 묶음 제목 「✈️ 여행 혜택 · N/M개 남음」(로그인) / 「M개」(비로그인). [구현]

1-4. 광고 카드

요소 내용 근거
썸네일 어드민이 올린 이미지 · 없으면 아이콘 [구현]
보상 「+NP」 [구현]
제목 · 광고주 어드민 값 [구현]
버튼 어드민 「버튼명」(4자 이내 · 예: 보러가기 · 가입하기) [구현]
받은 광고 버튼 대신 「✓ 적립완료」 · 누르면 토스트 "이미 적립한 혜택이에요" [구현]

1-5. 참여 흐름 [구현]

  1. 카드를 누른다 → 비로그인이면 로그인 시트 · 본인인증 전이면 본인인증 시트(F-AUTH S6 — 다녀온 뒤 막히면 광고만 보고 못 받으므로 나가기 전에 묻는다).
  2. 광고 페이지를 새 창으로 연다 + 토스트 "{광고주} 페이지에서 N초 머물면 적립돼요".
  3. 광고 페이지에서 N초가 지나면 적립 → 알림 「혜택 적립 +NP」(알림 정책서 2절).
  4. 광고 창에서 적립이 끝나면 픽콕 창에 결과를 알린다 → 잔액·목록을 다시 받아 「적립완료」로 바뀌고, 적립됐을 때만 다른 적립처럼 적립 연출("NP 적립! · {광고주} 혜택 참여 완료"). 실패·이미 참여·비로그인은 광고 창이 이유를 보여주고 픽콕은 목록만 갱신. 창을 닫고 돌아와도 목록을 갱신한다 (10-28 크로스체크 — 대화창4) [PO 확정 2026-10-28] Q11 · [구현] (K4 — 전에는 창을 noopener로 열어 알림이 닿지 않았음)

1-6. 아래 안내

"표시된 혜택은 광고이며, 광고주가 제공합니다." · "같은 혜택은 한 번만 적립돼요." (셋째 줄 "시연용 가상 데이터"는 시연 안내) [구현]

2. 광고 페이지 (구현 = 시연용 대체 화면)

실제 서비스에서는 광고주 페이지로 바로 간다. 체류 확인·적립 통보 방식(중개사 포스트백 등)은 정해지지 않았다 — 미결 R-O1. 아래는 시연 화면의 동작이다.

상태 표시 근거
기다리는 중 숫자 카운트(N → 1) · "조금만 기다려 주세요 · 이 화면에 N초 머물면 NP가 적립돼요" · "적립이 끝나면 이동 버튼이 나타나요" [구현]
적립됨 ✓ · "NP 적립됐어요! · 픽콕으로 돌아가면 포인트가 올라가 있어요" · [광고주 페이지로 이동하기] → 광고주 링크 (10-28 크로스체크 — 대화창4) [구현]
이미 참여 ✓ · "이미 참여한 혜택이에요 · 같은 광고는 한 번만 적립돼요" · [광고주 페이지로 이동하기] [구현]
비로그인 ✓ · "로그인이 필요해요 · 픽콕에서 로그인한 뒤 다시 참여해 주세요" · [광고주 페이지로 이동하기] [구현] — 버튼은 창을 닫지 않고 그 창을 광고주로 옮기므로 이름을 「창 닫고 이동하기」에서 바꿈 (K4)
실패 "적립하지 못했어요" + 서버 사유 [구현]
위쪽 광고주 주소 · 「광고」 표시 [구현]
  • 서버 적립 조건: 로그인 · 본인인증 · 광고가 노출 중(노출 기간 안 — 목록만이 아니라 광고 페이지·적립도 기간을 본다 (10-28 크로스체크 — 대화창4) Q12) · 처음 참여 · 체류 초 이상. 이미 참여면 "이미 참여한 광고예요", 종료면 "종료된 광고예요". [구현]
  • ⚠ 구현은 체류 시간을 화면이 서버에 알려 준 값으로 판단한다 — 실제 서비스는 중개사·광고주 쪽 확인으로 바꿔야 한다(#48 · R-O1).
