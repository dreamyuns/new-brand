1-2. 저금통 방식 — 미결 R-U8

구현은 시연 화면의 A·B 전환 장치로 현금 전환(A) / 픽샵(B) 을 바꿔 보인다. 실제 서비스에서 하나로 고를지, 둘 다 열지는 정하지 않았다(홈 「저금통 A·B안 택1」 · 마이페이지 R-Y3와 같은 건).

2. 현금 전환 (A안)

현금 전환이 전자금융거래법상 선불업 등록 대상인지는 미결이다(R-U1). 구현은 화면 안내 문구에서만 이 경고를 뺐다(PO 2026-10-07) — 정책 미결은 그대로다.

2-1. 단계

계좌 등록 → 1원 인증 → 금액 신청 3단계. 단계 표시 「1 계좌 등록 · 2 계좌 인증 · 3 금액 신청」. [구현] 한 번 인증한 계좌는 서버에 저장되어 다음부터는 3단계(금액)부터 시작한다. [구현]

2-2. 계좌 등록

항목 규칙 근거

2-3. 1원 인증

  • 「1원을 보냈어요」 · 은행·가린 계좌번호 → 입금자명 뒤 4자리 입력 → [계좌 인증 완료] → 계좌 저장 · 토스트 "계좌가 등록됐어요. 다음부터는 바로 신청할 수 있어요". [구현]
  • 숫자가 다르면 토스트 "숫자가 달라요. 입금자명을 다시 확인해 주세요". [1원 다시 보내기]. [구현]
  • 시연: 실제 1원 송금·예금주 대조가 없고, 화면에 정답 4자리를 보여 준다. 실서비스는 계좌 인증 업체 연동이 필요하다. [구현] 미결 R-U5
