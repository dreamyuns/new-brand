⚙ 공통 정책 — 공급사별 포인트 현황
  • 데이터 소스: KAYAK Reporting API — ProviderCode 기준으로 OTA별 집계 (6조)
  • 날짜 기준: 적립완료일(체크아웃+7일 자사 배치 처리 완료 시점) 기준. 실제로 포인트가 지급된 건만 집계 (6-2절)
  • 집계 범위: 적립완료(자사 Approved) 건만 표시. 적립예정(Active)·취소(Cancelled) 건 제외. 이 화면은 실제 지급된 포인트 정산 확인 용도
  • 포인트 단위: P (포인트), 1P = 1원. KAYAK 정산 기준 KRW로 통일 (6-4절)
  • 검색 기간: [최근 1주일] · [최근 1달] · [직접 입력] 3가지 버튼 선택. 퀵 버튼 클릭 시 날짜 필드에 해당 기간 자동 채움·수정 불가(회색)·즉시 조회. [직접 입력] 클릭 시 날짜 필드 활성화·수동 입력 후 [조회] 버튼 클릭. 최대 365일
  • MVP 조회전용: 포인트율 수동 조정 기능 없음 (Phase 2 후 논의)
기준: 어드민 v0.7 6조 / 검색 조건 공통 규칙

주석 — ADM-CB02

1
날짜 필터 — 3가지 버튼 선택
  • 집계 기준: 적립완료일. 포인트가 실제로 지급된 날짜(체크아웃+7일 자사 배치 시점)를 기준으로 기간을 선택
  • [최근 1주일] (기본): 화면이 처음 열릴 때 선택 상태. 오늘 포함 7일간 적립완료 건 집계. 클릭 즉시 조회. 날짜 필드에 해당 기간(예: 2026-08-04 ~ 2026-08-11)이 자동으로 채워지고 수정 불가(회색 배경)
  • [최근 1달]: 오늘 포함 30일간 집계. 클릭 즉시 조회. 날짜 필드에 해당 기간 자동 채움·수정 불가
  • [직접 입력]: 클릭 시 날짜 필드가 흰 배경으로 바뀌고 값이 지워져 직접 입력 가능. 시작일~종료일 입력 후 [조회] 버튼 클릭으로 실행. [조회] 버튼은 날짜 입력 후 활성화됨
  • [최근 1주일] 또는 [최근 1달] 선택 시 날짜 필드는 다시 자동 채움·수정 불가 상태로 돌아가고 [조회] 버튼은 비활성화됨
  • 최대 365일 초과 입력 시 오류 메시지 표시 + [조회] 버튼 비활성
검색 조건 공통 규칙 — 적립완료일 기준 / 최근 1주일(기본) / 최대 365일
2
공급사별 집계 테이블
  • 각 OTA별로 조회 기간 내 적립완료된 건 수와 포인트 합계를 한눈에 볼 수 있음
  • 적립예정·취소 건은 제외. 실제 지급된 포인트만 집계 → 정산·검증 용도에 적합
  • 정렬: 적립완료 건수 내림차순 (가장 많이 적립된 공급사 최상단)
  • 조회 기간 내 적립완료 건이 없는 공급사는 목록에서 제외
어드민 v0.7 6-2절 — 적립완료 기준 집계
3
적립완료 건수 컬럼
  • 조회 기간 내 해당 공급사에서 적립완료(자사 Approved 처리 완료)된 예약 건 수
  • 적립예정·취소 건은 이 숫자에 포함되지 않음
어드민 v0.7 5-2절 — 적립완료 정의 (체크아웃+7일 자사 배치 처리 완료)
4
포인트 합계(P) 컬럼
  • 적립완료 건들의 CashbackAmountLocalised 합계. 단위 P (포인트), 1P = 1원. 소수점 이하 버림
  • NONE/null 타입 공급사(포인트 미제공)는 합계가 없으므로 "—" 표시
어드민 v0.7 6-2절·6-4절 — Approved 누적합계 / 소수점 버림
5
포인트율/금액 · 타입 컬럼
  • KAYAK API에서 받아오는 CashbackType·CashbackValue 값을 그대로 표시. 자사 재계산 없음
  • PERCENTAGE 타입: 포인트율(%)만 표시 — 예: 3.2% (예약금액의 3.2%를 포인트로 줌)
  • FLAT 타입: 고정 금액(₩)만 표시 — 예: ₩6,000 (예약금액과 무관하게 이 금액을 줌)
  • NONE/null: 포인트 미제공 공급사. 포인트율·금액 "—", 타입 배지 "NONE" 표시
어드민 v0.7 6-4절 — KAYAK CashbackType/CashbackValue 기반. 자사 재계산 없음
포인트율 조정 공급사별 포인트율 조정은 KAYAK 담당자에게 양식을 제출하는 방식으로 진행.
어드민 화면에서 직접 변경할 수 없음. Phase 2에서 조정 이력 조회 기능 논의 예정.
