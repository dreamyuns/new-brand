⚙ 공통 정책 — 공급사별 포인트 현황
  • 데이터 소스: KAYAK Reporting API — ProviderCode 기준으로 OTA별로 집계 (6조)
  • 날짜 기준: 예약일(BookingDate) 기준. YYYY-MM-DD 날짜 단위 범위 선택 (6-2절)
  • 집계 기준: 적립완료(Approved) 건 기준. 적립예정(Active)·취소(Cancelled) 건은 별도 표시 (6-2절)
  • 포인트 단위: P (포인트), 1P = 1원. KAYAK 정산 기준 KRW로 통일 (6-4절)
  • MVP 조회전용: 포인트율 수동 조정 기능 없음 (Phase 2 후 논의)
기준: 어드민 v0.5 6조

주석 — ADM-CB02

1
예약일 날짜 범위 선택
  • 집계 기준: 예약일(BookingDate). 고객이 OTA에서 예약을 완료한 날짜를 기준으로 기간을 선택
  • 전체 (디폴트): 라디오에서 "전체" 선택 시 날짜 입력창 비활성(흐림). 서비스 시작일~오늘까지 전체 누적 집계
  • 기간 선택: 라디오에서 "기간 선택" 클릭 시 시작일 입력창 활성화
  • 시작일만 입력 → 그날 하루만 집계 (종료일 = 시작일 자동 적용)
  • 시작일·종료일 모두 입력 → 그 날짜 범위 내 예약일 기준 집계
  • 종료일 입력창은 시작일 입력 후 활성화됨. 종료일만 단독 입력 불가
  • 날짜 형식: YYYY-MM-DD (예: 2026-06-01)
2
공급사별 집계 테이블
  • 각 OTA(타사 예약 사이트)별로 예약 건수와 포인트 합계를 한 눈에 볼 수 있음
  • 포인트 합계는 P(포인트) 단위로 표시. 1P = 1원 기준
  • 포인트율 평균: PERCENTAGE 타입 OTA에만 계산. FLAT 타입 또는 CashbackType이 null인 OTA는 "—"으로 표시
  • CashbackType이 null인 OTA: 포인트가 없어도 예약 건수는 집계됨
어드민 v0.3 6-4절 — 포인트 단위 P, 1P=1원
3
포인트율/금액 · 타입 컬럼
  • KAYAK API에서 받아오는 값을 그대로 표시. 자사에서 별도 계산하지 않음 (현재 적용 기준 따름)
  • PERCENTAGE 타입: 포인트율(%)만 표시 — 예: 3.2% (예약금액의 3.2%를 포인트로 줌)
  • FLAT 타입: 고정 포인트 금액만 표시 — 예: 240,000P (예약금액과 무관하게 항상 이 금액을 줌)
  • 미설정 (null): "—" 표시 — 포인트가 없는 OTA
  • 두 값(% + 금액)을 한 행에 같이 표시하지 않음. 타입에 따라 하나만 표시
어드민 v0.3 6-4절 — KAYAK 포인트 타입 구분. 자사 재계산 없음
4
포인트 합계 컬럼
  • 적립완료(Approved) 상태인 건들의 포인트 누적 합계만 표시
  • 적립예정(Active)·취소·만료(Cancelled) 건의 포인트는 이 합계에 포함되지 않음. 각각 Active·Cancelled 카운트 컬럼에서 별도 확인
  • 단위는 P(포인트). 1P = 1원 기준. 소수점 이하 버림
어드민 v0.3 6-2절·6-4절 — Approved 누적합계 기준
5
적립예정 · 적립완료 · Cancelled 카운트 컬럼
  • 세 컬럼 모두 TransactionType="Booking"인 건만 집계. Click 건은 포함하지 않음
  • 적립예정 (TransactionType="Booking" + TransactionStatus="Active"): 체크아웃 전이거나 자사 기준 통과 전인 예약 건 수
  • 적립완료 (자사 내부 Approved 판정): 체크아웃+7일 후 자사 배치 처리로 포인트가 확정된 예약 건 수. KAYAK API의 TransactionStatus와 직접 대응하지 않음 (포인트_정책서 v0.1 2-1절)
  • Cancelled (TransactionType="Booking" + TransactionStatus="Cancelled"): 예약이 취소됐거나 포인트가 만료된 건 수. PERCENTAGE 타입이어도 포인트가 0인 실데이터 존재
  • 예약 건수 컬럼 = 적립예정 + 적립완료 + Cancelled 합계
어드민 v0.5 6-2절 — TransactionType/TransactionStatus 정의
포인트율 조정 공급사별 포인트율 조정은 KAYAK 담당자에게 양식을 제출하는 방식으로 진행.
어드민 화면에서 직접 변경할 수 없음. Phase 2에서 조정 이력 조회 기능 논의 예정.
