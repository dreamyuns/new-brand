주석 — ADM-MEM02 (케이스 A)

1
이메일 (읽기전용)
  • 이 서비스는 이메일 인증코드로 로그인하기 때문에, 이메일이 계정을 구분하는 유일한 식별자임 → 수정 불가
  • "인증완료" 배지는 이메일 인증이 완료된 계정임을 항상 표시
정책서 v0.44 8-2절 — 이메일 인증코드 방식
2
이름·성 수정
  • 영문(알파벳)만 입력 가능. 한글 입력 시 유효성 오류 메시지 표시
  • 선택 항목 — 입력하지 않아도 저장 가능
3
국적 변경
  • [변경] 버튼 클릭 → 국가 선택 팝업(바텀시트) 열림 — 프런트 화면 MY03(계정관리) 패턴 참조
  • 국가 목록은 KAYAK Constants API에서 가져온 국가 목록 기반
4
전화번호
  • 국가 코드(예: +82)와 전화번호를 따로 입력. 형식: 010-XXXX-XXXX
  • 숫자와 하이픈(-)만 허용. 선택 항목 — 입력 안 해도 저장 가능
6
포인트 내역 탭 (케이스 C 참조)
  • 해당 회원에게 귀속된 포인트 내역을 조회. KAYAK Reporting API의 labels 파라미터에 회원 ID를 넣어 해당 회원 포인트만 가져옴
  • MVP에서는 조회 전용 — 수동 지급·삭제·회수 없음
어드민 v0.5 6조
7
[저장] 버튼
