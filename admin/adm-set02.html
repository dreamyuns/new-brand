주석 — ADM-SET02

1
마지막 로그인 (읽기전용)
  • 자사 DB 로그인 이력 테이블에서 가장 최근 기록을 가져와서 보여줌
  • 수정 불가. 시스템이 자동으로 기록하는 값
2
현재 세션 (읽기전용)
  • 지금 이 계정이 어드민에 로그인 되어있는지 여부. 활성 = 현재 사용 중
  • 세션 만료 시간은 아직 정해지지 않은 상태 — 나중에 보안 정책이 확정되면 반영 (8조 미결 1)
  • 수정 불가. 시스템이 자동으로 관리하는 값
세션 만료 시간 미확정 — 보안 정책 확정 필요 (8조 미결 1)
3
아이디 (읽기전용)
  • 처음 계정이 만들어질 때 발급된 아이디. 이후 변경 불가
  • "마스터" 배지로 이 계정의 권한 등급을 한눈에 확인 가능
어드민 v0.2 7-2절 — 아이디 고정 정책
4
권한 셀렉트
  • 마스터: 어드민 전체 기능에 접근 가능. MVP 유일 권한
  • 서브 (선택 불가): Phase 2에서 활성화 예정. 지금은 선택 자체가 막혀 있음
  • MVP에서는 마스터 고정이므로 실제 변경 불가 — 저장 버튼을 눌러도 마스터로만 처리됨
어드민 v0.2 7-2절 — 서브 권한 Phase 2 예정
5
상태 셀렉트
  • 활성: 이 계정으로 어드민 로그인 가능한 상태
  • 비활성: 로그인 즉시 차단. 계정을 삭제하지 않고 접근만 막을 때 사용
  • 저장 버튼을 누르면 바로 적용됨. 비활성으로 바꾸면 현재 접속 중인 세션도 종료됨
어드민 v0.2 7-2절 — 비활성 처리 정책
6
비밀번호 변경 폼
  • 지금 쓰고 있는 비밀번호를 먼저 입력해서 본인 확인 후 변경 허용
  • 새 비밀번호 규칙: 영문+숫자+특수문자 조합, 8자 이상
  • 새 비밀번호는 현재 비밀번호와 달라야 함
비밀번호 복잡도 기준 — 보안 정책 확정 후 반영 (8조 미결 1)
7
[비밀번호 변경] 버튼
  • 3개 필드 모두 입력하고 규칙을 통과해야 버튼이 활성화됨
  • 변경 성공 시: "비밀번호가 변경되었습니다" 메시지 표시 후 자동 로그아웃 → 재로그인 유도
  • 현재 비밀번호 틀림: "현재 비밀번호가 올바르지 않습니다" 오류 표시
  • 새 비밀번호 두 칸이 다름: "비밀번호가 일치하지 않습니다" 오류 표시
프론트: 변경 성공 후 자동 로그아웃 처리 — 보안 정책 확정 후 최종 결정
8
[삭제 요청] 버튼
  • 버튼을 누르면 "정말 삭제하시겠습니까?" 확인 창이 나타남
  • 확인 시 백엔드 API에 삭제 요청을 보냄. 어드민 화면에서 직접 DB를 삭제하지 않음
  • 삭제 완료 시 해당 계정으로 로그인 불가. 어드민 접근 차단
  • 실수 방지를 위해 버튼 색을 빨간색으로 표시 (위험 영역)
