  • MVP에서는 마스터 고정이므로 실제 변경 불가 — 저장 버튼을 눌러도 마스터로만 처리됨

  • 저장 버튼을 누르면 바로 적용됨. 비활성으로 바꾸면 현재 접속 중인 세션도 종료됨
어드민 v0.2 7-2절 — 비활성 처리 정책

[비밀번호 변경] 버튼
  • 클릭 시 비밀번호 변경 팝업(모달)이 화면 위에 열림
  • 팝업 구성: 현재 비밀번호 / 새 비밀번호 / 새 비밀번호 확인 3개 입력 칸 + [취소] [변경] 버튼
  • [취소] 버튼 클릭 또는 팝업 바깥 영역 클릭 → 팝업 닫힘, 입력값 초기화
7
팝업 [변경] 버튼 — 유효성 검사
  • 비밀번호 규칙 (정책): 영문+숫자+특수문자 조합, 8자 이상
  • 3개 입력 칸이 모두 채워져야 [변경] 버튼 활성화. 하나라도 비어 있으면 버튼 비활성(회색)
  • 유효성 검사 실패 케이스 (각 실패 시 해당 칸 테두리 빨간색 강조 + 칸 아래 오류 메시지 표시):
    • ① 현재 비밀번호 틀림 → "현재 비밀번호가 올바르지 않습니다"
    • ② 새 비밀번호 규칙 미충족 (8자 미만, 또는 영문·숫자·특수문자 중 하나 이상 없음) → "영문·숫자·특수문자를 모두 포함해야 합니다 (8자 이상)"
    • ③ 새 비밀번호가 현재 비밀번호와 동일 → "현재 비밀번호와 다른 비밀번호를 입력해 주세요"
    • ④ 새 비밀번호 확인 칸 불일치 → "비밀번호가 일치하지 않습니다"
  • 변경 성공 시: 팝업 닫힘 + "비밀번호가 변경되었습니다" 토스트 메시지 표시. 자동 로그아웃 여부는 보안 정책 확정 후 결정

9
이메일 입력 (필수)
  • 이메일 형식(예: name@company.com) 맞지 않으면 → "올바른 이메일 형식을 입력해 주세요" 오류 표시
  • 이미 사용 중인 이메일 입력 시 → "이미 사용 중인 이메일입니다" 오류 메시지
  • 비밀번호 찾기·로그인 알림 등에 사용됨
10
이름 입력 (선택)

11
초기 비밀번호 입력 (필수)

  • 비밀번호 확인 칸과 일치하지 않으면 → "비밀번호가 일치하지 않습니다" 오류
  • 규칙 미충족 시 → "영문·숫자·특수문자를 모두 포함해야 합니다 (8자 이상)" 오류
  • 등록 후 해당 관리자에게 초기 비밀번호를 직접 전달. 첫 로그인 후 변경 권장 (정책 미결)
