주석 — ADM-BOOK01 (어드민 v0.7 5-3절)

1
요약 통계
  • 현재 필터 조건을 반영한 건수 집계. 필터 적용 시 동적으로 숫자가 바뀜
  • 전체 예약 = 적립예정 + 적립완료 + 취소 합계
2
전체 예약
  • KAYAK Reporting API에서 TransactionType=Booking인 예약완료 건의 누적 합계
  • 계산식: 적립예정 + 적립완료 + 취소 합계
  • 현재 필터 조건(기간·공급사·회원 등) 적용 시 해당 조건에 맞는 건수만 집계
어드민 v0.7 5-1절 — TransactionType=Booking 기준
3
적립예정
  • 체크아웃 날짜 + 7일이 아직 지나지 않은 건
  • 또는 체크아웃+7일이 지났지만 자사 배치 처리가 아직 실행되지 않은 건
  • KAYAK 상태가 Cancelled가 아닌 활성 예약 중 포인트 미지급 건
어드민 v0.7 5-2절 — 적립예정 정의
4
적립완료
  • 체크아웃 날짜 + 7일 후 자사 배치가 실행되어 포인트 지급이 완료된 건
  • 계산식: 적립완료일 = 체크아웃 날짜(BookingEndDate) + 7일
  • KAYAK Reporting API TransactionStatus=Approved에 해당하는 건
어드민 v0.7 5-2절 — 적립완료 정의 / 계산식
5
취소
  • KAYAK Reporting API에서 TransactionStatus=Cancelled가 감지된 건
  • 취소 건은 포인트 지급 대상에서 제외. 포인트(P)·적립완료일 컬럼에 "—" 표시
  • 만료(적립 기간 초과) 처리는 Phase 2 이후 정책 확정 예정
어드민 v0.7 5-2절 — 취소 정의 / TransactionStatus=Cancelled
6
기간 기준 선택 (예약일 / 체크인일)
  • 예약일(기본): 고객이 OTA에서 예약을 완료한 날짜(BookingDate) 기준으로 조회
  • 체크인일: 체크인 날짜(BookingStartDate) 기준으로 조회. CS 대응 시 "몇 월에 투숙한 건" 찾을 때 유용
어드민 v0.7 5-3절 — 기간 기준 선택
7
기간 범위 기본값 (최근 1년)
  • 기본값: 화면이 처음 열릴 때 자동으로 오늘 기준 정확히 1년 전 ~ 오늘로 채워짐
  • 관리자가 날짜를 직접 수정해 조회 범위 변경 가능
어드민 v0.7 5-3절 — 기간 기본값 1년 고정
8
회원/비회원 필터
  • 전체(기본): 회원·비회원 예약 모두 표시
  • 회원: 회원ID가 매핑된 건만 표시 (labels 파라미터 귀속 완료)
  • 비회원: 회원ID가 "—"인 건만 표시 (비로그인 이동, 포인트 미귀속)
어드민 v0.7 5-3절 — 회원/비회원 필터
9
포인트 상태 (필터 및 컬럼)
  • 적립예정: 체크아웃+7일이 아직 지나지 않은 건. 자사 배치 미실행
  • 적립완료: 체크아웃+7일 후 자사 배치 처리가 완료된 건
  • 취소: KAYAK에서 Cancelled 상태가 감지된 건. 만료는 Phase 2 이후 정책 확정
어드민 v0.7 5-2절 — 포인트 상태 자사 정의
10
공급사(OTA) — 필터 및 컬럼
  • 실제 예약 데이터에 있는 OTA 이름을 불러와 목록으로 보여줌 (고정 목록 아님)
  • KAYAK API ProviderCode 기반. 코드를 사람이 읽기 쉬운 이름으로 변환해 표시
  • 컬럼에는 OTA 이름 텍스트만 표시. OTA 로고 이미지 없음
어드민 v0.7 5-3절 — 공급사 표시
11
통합 검색
  • 이메일 주소(예: hong@example.com) 또는 예약번호(예: RES-20042)로 특정 건을 찾을 수 있음
  • 검색 결과는 현재 필터 조건과 함께 적용됨
어드민 v0.7 5-3절 — 검색·필터
12
회원ID
  • 아웃링크 URL에 심은 labels 파라미터로 자사 회원 이메일을 전달 → Reporting API에서 귀속 확인
  • 이메일이 곧 회원 식별자. 비로그인 상태로 아웃링크 이동한 건: labels 없음 → "—" 표시 (이 경우 포인트 귀속 불가)
  • labels↔이메일 매핑 방식은 개발팀 논의 예정 (8조 미결 #8)
어드민 v0.7 5-3절 / 정책서 v0.45 9절 — 비로그인 귀속 불가
13
예약번호 (BookingID)
  • KAYAK Reporting API에서 내려오는 예약 고유 번호
  • CS 상담 시 고객이 말하는 예약번호로 빠르게 찾을 수 있는 컬럼
KAYAK Reporting API — BookingID 필드
14
예약일 (BookingDate)
  • 고객이 예약을 완료한 날짜. 체크인 날짜와 다름
  • CS 상담 시 예약 시점 파악 또는 분쟁 기준일로 활용
15
호텔명 (HotelName)
  • KAYAK API에서 내려오는 호텔 이름 그대로 표시. 빈값 가능 → "—" 표시
16
투숙기간
  • 체크인~체크아웃 날짜를 한 컬럼에 묶어 표시. 예: "07.01 ~ 07.03"
  • API: BookingStartDate(체크인) / BookingEndDate(체크아웃)
  • 적립완료일 기준: 체크아웃 날짜 + 7일 후 자사 배치 실행 시 전환
어드민 v0.7 5-3절 — 투숙기간 통합 컬럼 / 5-2절 적립완료일 기준
17
포인트(P)
  • KAYAK API CashbackAmountLocalised (원화 환산). 1P = 1원
  • CashbackType=NONE 또는 null 건(포인트 없는 공급사): "—" 표시
  • 소수점 이하 버림. 예: 9,623.4 → 9,623P
어드민 v0.7 5-3절 / 포인트_정책서 v0.1 2-2절 — 소수점 버림
18
타입 (CashbackType)
  • PERCENTAGE: 예약금액의 몇 %를 포인트로 줌
  • FLAT: 예약금액과 관계없이 정해진 포인트를 그대로 줌
  • NONE/null: "—" 표시
19
적립완료일
  • 체크아웃 날짜 + 7일로 계산한 날짜. 형식: YYYY-MM-DD
  • 적립완료 건: 자사 배치가 실행된 날짜
  • 적립예정 건: 예정일(YYYY-MM-DD) 표시
  • 취소 건: "—" 표시
